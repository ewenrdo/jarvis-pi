# Installer Netflix sur Kodi
Guide rapide : Installer Netflix sur Kodi
1. Prérequis indispensable

Assurez-vous que le module de décryptage des flux est actif :
-  Allez dans Add-ons > Mes add-ons > Modules vidéos.
- Vérifiez que InputStream Adaptive est présent et activé.

2. Télécharger le dépôt CastagnaIT (via Terminal)

Le dépôt officiel pour Netflix (maintenu par CastagnaIT) s'installe via un fichier .zip. Téléchargez-le directement en ligne de commande :
```
wget https://github.com/CastagnaIT/repository.castagnait/raw/kodi/repository.castagnait-2.0.1.zip -O ~/repository.castagnait.zip
```

3. Installer le dépôt dans Kodi.
- Dans Kodi, allez dans Add-ons > Installer depuis un fichier zip (icône de boîte ouverte).
- Sélectionnez Home folder (Dossier personnel).
- Choisissez le fichier repository.castagnait.zip que vous venez de télécharger.

4. Installer l'addon Netflix
- Allez dans Installer depuis un dépôt > CastagnaIT repository > Add-ons vidéo.
- Sélectionnez Netflix et cliquez sur Installer.
- Lors du premier lancement, connectez-vous à votre compte à l'aide de la méthode d'authentification sécurisée (code de liaison).
